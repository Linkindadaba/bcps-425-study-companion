Module 1 High Performance Computing (HPC) & Parallel Architectures

Parallel Computing: Multiple processors in a single machine executing sub-tasks concurrently to increase speed.

Distributed Computing: Autonomous computers connected over a network coordinating via message passing.

Speedup Formula: S(p) = T1 / Tp

Amdahl's Law: S(p) = 1 / ((1 - f) + (f / p)) where (1 - f) is the serial portion.

Flynn's Taxonomy

  • SISD: Single Instruction, Single Data (Legacy single core).
  • SIMD: Single Instruction, Multiple Data (Vector processors, GPUs).
  • MISD: Multiple Instruction, Single Data (Space shuttle flight control).
  • MIMD: Multiple Instruction, Multiple Data (Multi-core CPUs, clusters).

Module 2 3-Tier & Client-Server Architecture

  • Tier 1 (Presentation): Client User Interface (Browser, Mobile App).
  • Tier 2 (Application Logic): Server executing business rules and processing requests.
  • Tier 3 (Data Layer): Database Management System (MySQL, PostgreSQL, S3).

Key Benefits: Independent horizontal scalability of layers, maintainability of business logic without UI code changes, and database security isolation.

Module 3 Concurrency, Race Conditions & Lost Update

Race Condition: System behavior depends on the timing/sequence of execution threads.

Lost Update Problem: Two users read the same record simultaneously, both update locally, and the second write overwrites the first user's change.

Remedies: Pessimistic Locking (SELECT ... FOR UPDATE) or Optimistic Concurrency Control (version timestamps).

Module 4 Deadlocks (Coffman Conditions & Strategies)

4 Coffman Conditions (Must all hold):

  1. Mutual Exclusion: Non-shareable resource.
  2. Hold and Wait: Holding resource while waiting for another.
  3. No Preemption: Resources released only voluntarily.
  4. Circular Wait: Closed loop process wait graph.

Handling Strategies

Prevention: Enforce total resource request ordering to break Circular Wait.

Avoidance: Dynamic evaluation via Banker's Algorithm for safe states.

Detection & Recovery: Cycle detection on Wait-For graphs & victim process rollback.

💡 Coulouris Textbook Q&A Bank

Q1: RMI Invocation Semantics?

Maybe: 0 or 1 execution (no retransmit).
At-Least-Once: 1+ executions (retransmits on timeout, safe for idempotent calls).
At-Most-Once: 0 or 1 execution (retransmits with duplicate reply history filtering).

Q2: Is Appending to a file Idempotent?

No. Each append increases file length. Writing to a fixed offset IS idempotent.

Q3: CORBA CDR vs XML Data Typing?

CORBA CDR uses static pre-compiled IDL files, removing type tag overhead for compact binary transport. XML is self-describing with textual tags, increasing payload size.
